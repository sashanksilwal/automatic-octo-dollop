# Twenty thirty-second walking tests

The two five-minute PAL3.0 sessions supply **20 non-overlapping 30-second walking tests**, ten per session, using the course counting interpretation confirmed by the operator. The first 300 measured seconds of each session are partitioned at 0, 30, ..., 300 seconds. Tiny timer tails remain in the original session summaries but add no test.

`tests.csv` retains the session ID, test bounds, observed receive/inference counts and actual fps for every test, including zero-delivery windows. Tests within a session share conditions and may be correlated. These are 20 tests from two recording sessions, not 20 separately recorded sessions or independent participants.

The November 4 session had four receive gaps over 500 ms (maximum 15.13 s). The November 18 session had one 148.99 s gap, a stopped/restarted phone relay and an operator pause. No interrupted window is removed or replaced. Both sessions passed three-device frame-envelope verification. Original session summaries and raw traces remain unchanged.

Source windows: `results/part-c/pal30-walking-pilot-2026-11-04/summary.json` and `results/part-c/pal30-walking-pilot-2026-11-18/summary.json`, field `correlated_30s_windows`, generated by `Bonus-PartC/analyze_pilot.py`. Twenty tests total 600 seconds; existing field-time totals count those same sessions once.
